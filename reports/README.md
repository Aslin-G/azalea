# Informes

Los informes que genera la aplicación se descargan en la carpeta de descargas del navegador
(botones **DESCARGAR INFORME HTML** / **IMPRIMIR / GUARDAR COMO PDF**). Puede guardarlos aquí para
conservarlos junto al proyecto.

Ejemplos incluidos (generados con los **DATOS SINTÉTICOS DE DEMOSTRACIÓN — NO SON DATOS REALES**, operación RUN-2026-001):

| Archivo | Contenido |
|---|---|
| `ejemplo_informe_tecnico_DEMO_SINTETICO.html` / `.pdf` | Informe técnico completo (14 secciones + simulación del sistema, fórmulas, métricas, gráficos) |
| `ejemplo_informe_ejecutivo_DEMO_SINTETICO.html` / `.pdf` | Informe ejecutivo (problema, resultado, riesgo, decisión, recomendación) |
| `ejemplo_manual_instalacion_hibrido.html` / `.pdf` | Manual de instalación generado por **Proyecto FV** (sistema híbrido de ejemplo, La Guajira, recurso estimado sin consultar NASA POWER) |
| `ejemplo_presupuesto_hibrido.html` / `.pdf` | Presupuesto editable exportado (precios referenciales COP 2026, sin cotizaciones reales) |

Los archivos HTML son autónomos (estilos y gráficos incluidos) y se abren sin internet.
